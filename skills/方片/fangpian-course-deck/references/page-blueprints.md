# 14 页页面蓝图

每页给出：目的、版式（用哪几个模块）、范例文案。做新课时**保持模块组合与顺序**，替换内容即可。坐标比例见 `design-system.md`。

## 第一幕 · 开场（2 页）

### P1 封面
- 版式：左文右图。黄色胶囊（课程归属）+ 超大黑色主标题 + 黑色副标题 + 灰色标签行；右侧一个**方片黄大底方块**（x54% y14% w42% h75%）放招手虎；左下角可放黑描边圆/黄小方块装饰。
- 文案：胶囊"方片 KOS 培训部 · AI 实战课"；主标题"AI 小白实战课"；副标题"把活儿说清楚，让 AI 替你干"；标签"零基础 · 拿来即用 · 今天就能上手"。
- 老虎：`01-pointing-cover.png`。

### P2 课程地图
- 版式：页头（黄 kicker"课程地图" + 黑大标题"今天，咱学会这 4 件事"）；中部 4 列横排，每列 = 黑方块编号(01–04) + 黑色方法名 + 黄色胶囊小标签 + 灰色一句话；底部黑色全宽金句条（学习目标）。
- 范例：01 说对话/提示词/把活儿给 AI 交代清楚；02 用技能/Skill/套路存下来下次直接用；03 抓数据/数据爬取/帮你扒抖音小红书；04 会借力/工具+协作/不单打独斗。
- 金句："学完目标：会写提示词、敢动手 —— 今天下班就能用上"。

## 第二幕 · 建立认知（1 页）

### P3 核心认知
- 版式：页头（黄 kicker"核心认知" + 黑大标题"AI 像新来的实习生"）；左侧 3 条编号要点（01/02/03 黄数字 + 黑结论 + 灰说明）；右侧浅黄方块 + 教师虎。
- 范例要点：01 你随口一句"帮我弄一下"，它只能凭感觉瞎猜；02 你说得越清楚，它干得越靠谱；03 写提示词就是派活，这门手艺叫"提示词工程"。
- 目的：用一个生活化比喻消除恐惧、点出全课主线。

## 第三幕 · 方法一 说对话（提示词，3 页）

### P4 方法概念页（整幅信息图）
- 版式：页头（kicker"方法一 · 写提示词" + 标题"好提示词的 5 个零件" + 灰副标题）；中央整幅品牌信息图（`assets/infographics/01-five-parts.png`）。
- 五零件：角色（让谁来做）/ 背景（为什么做给谁看）/ 输入（做什么用什么资料）/ 输出（交成什么样）/ 示例（参考什么答案）。
- 新主题：用同一卡片样式重做一张"五步法"信息图。

### P5 现场演示页（步骤流）
- 版式：页头（"方法一 · 实战演示" + 标题"现场练一个：把群聊整理成纪要"）；左栏 5 个黄方块编号步骤（编号 + 黑步骤名 + 灰说明）；右栏浅黄方块 + 西装公文虎；底部金句条。
- 步骤：1 说清楚 / 2 定角色 / 3 给背景 / 4 限格式 / 5 给示例。
- 金句："一句话：越像给新人派活，结果越对味"。老虎 `03-suit-doc.png`。

### P6 好习惯页（双信息图）
- 版式：页头（"方法一 · 好习惯" + 标题）；左右两张并列的整幅信息图（`02-one-task-one-chat.png`、`03-choose-model.png`），每张顶部黑色标题条；图下各一行灰说明；底部居中一句金句。
- 范例：习惯一 一个任务一段对话；习惯二 选对模型（长任务用长程模型，写文案用快模型）。

## 第七幕 · 收尾（3 页）

### P12 总结回顾（编号清单）
- 版式：页头（"总结回顾" + 标题"一张图回顾今天的 4 件事"）；左栏 4 个黄方块编号（01–04）+ 黑方法名 + 灰一句话；右侧浅黄方块 + 奖杯虎；底部金句条。
- 金句："把这 4 招用熟，就超过大部分同行"。老虎 `07-trophy.png`。

### P13 行动清单（勾选卡）
- 版式：页头（"行动清单" + 标题"回去先做这 3 件事"）；左栏 3 张白描边卡片，每张 = 36×36 黄勾选块 + 黑动作句 + 灰"怎么做"；右浅黄方块 + 点赞虎；底部灰句"有问题随时问，咱群里见"。
- 动作必须**今晚/明天可执行**，每条一动词起头。老虎 `08-thumb-action.png`。

### P14 金句收尾
- 版式：黑胶囊"最后一句" + 超大黑标题（4 字以内金句）+ 灰色副句 + 黑色落款；右侧浅黄方块 + 招手虎。
- 范例：金句"慢就是快"；副句"把一件事说清楚，胜过十件事都让 AI 猜"；落款"KOS 培训部 · 谢谢大家，咱们下回见"。老虎 `01-pointing-cover.png`。

## 页数伸缩

- 方法少于 4 个：合并/删减第三~六幕，每个方法至少保留"概念 + 演示"两页。
- 方法多于 4 个：每个方法复用"概念信息图 + 演示步骤 + 好习惯"三页模板，追加即可。
- 无论增减，P1/P2/P12/P13/P14 五页（封面、地图、总结、行动、金句）必须保留。
