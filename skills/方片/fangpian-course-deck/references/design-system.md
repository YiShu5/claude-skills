# 设计系统 · 精确规范

所有坐标以**画布百分比**给出（960×540 飞书 / 1280×720 PPT 通用）；括号内是 960×540 的 px 参考值。横向安全边距 x=5.7%（约 55px），纵向不低于 9%。

## 1. 色板

| 用途 | 色值 | 说明 |

| 页面底色 | `#FFFCF2` | 奶油底，**全页统一**，不用纯白 |

| 墨色/标题 | `#1A1A1A` | 暖黑（非纯黑）：大标题、黑方块、金句条底 |

| 辅助灰 | `#787464` | 副标题、标签注脚 |
| IP 衬底 | `#FFF0B4` | 小老虎背后的浅黄方块 |
| 卡片底 | `#FFFFFF` | 白描边卡片 |

## 2. 字体与字号

- 中文：**Noto Sans SC / 思源黑体**。大标题 Bold；正文 Regular。
- 亲和标签（黄色胶囊里的栏目名、口号）可用江城圆体 / ChillReunion Round。
- 英文与数字：**Nunito**（Skill、01–05、ModelScope、URL）。
- 大标题尽量短句、口语，数字用半角。

## 3. 版心与网格

- 左、右边距 ≈ 5.7%（55px / 73px）。
- 页头区：kicker 位于 y≈9.3%（50px）；大标题 y≈14.4%（78px）；副标题 y≈23% 左右。
- 内容区从 y≈27% 开始；底部金句条 y≈80–92%。
- **左文右图两栏**：正文/列表占宽 58%（x=5.7%→64%），右栏固定浅黄 IP 方块（x≈66–68%，宽 28%，高 50%，y≈28%）。
- 无老虎的页（如信息图、截图页）内容可铺到 94% 宽。

## 4. 八个模块尺寸（960×540）

1. **统一页头**：kicker 文本框 x55 y50 w360 h24（黄字）；大标题 x55 y78 w820 h48；副标题 x55 y132 w820 h24（灰）。
2. **黄色胶囊**：圆角矩形，黄底黑字，圆角=高/2；眉标胶囊约 x55 y84 w260 h40；行内小标签高 26、内边距左右 16。
3. **黑方块编号（01–04）**：48×48 黑底方块（圆角 4），内黄数字，居中；用于课程地图与总结，水平均分。
4. **黄方块编号（1–5）**：30×30 黄底方块，内黑数字；步骤流垂直排列，行距约 50px。
5. **黑色全宽金句条**：x55 y≈400 w850 h46，圆角 8，黑底，居中黄字 17–18px。
6. **白描边卡片**：x55 w560 h76（可堆叠，间距 14），白底 + 2pt 暖黑描边 + 圆角 10；内放 36×36 黄色勾选方块（x+22，垂直居中）+ 卡片标题（黑）+ 说明（灰）。
7. **浅黄 IP 方块**：x634 y151 w269 h270，填充 #FFF0B4，无描边；老虎透明 PNG 居中铺满（贴边或略出血）。
8. **整幅品牌信息图**：一张 16:9 或 16:6 的 PNG，置于内容区中央；自带黄色页眉胶囊、编号模块、教师虎、logo。
   - 信息图卡片视觉语言（供重做新主题时复刻）：白色圆角卡 + 黄色圆形编号徽章（01–05）+ 蓝色线性图标 + 黄色连接箭头 + 右下角戴眼镜教师虎 + 右上角黑色"方片"字标 + 顶部黄色胶囊标题 + 底部黄色金句条。
   - 参考 `assets/infographics/01-five-parts.png`（五步法）、`02`、`03`（并列双卡）。

## 5. 老虎使用规范

- 必须用**透明底**（assets/tigers 已抠好）；禁止白底、禁止拉伸变形；等比缩放。
- 放在 `#FFF0B4` 浅黄方块上，或信息图右下角；居中、可略出血，不要裁切头部。
- 一页只用一只主虎（信息图双卡内的教师虎除外）；同一只虎不要跨相邻页重复。
- 姿势按"情绪/任务"匹配，对照表见 SKILL.md。

## 6. 禁忌

- 不引入色板以外的颜色（尤其不用靛蓝/紫色做大面积）。
- 不用纯白底、不用 emoji；图标用统一的蓝色线性图标或黄色块。
- 正文不堆长句，每卡 1 个动词短句 + 1 行灰字说明。
- 金句条每页最多 1 条；老虎不重复画、不换色。
- 截图必须真实、清晰、必要时红框/箭头标注关键位置。
