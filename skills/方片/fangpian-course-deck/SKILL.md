# 方片培训课件模板（fangpian-course-deck）

把任何主题做成**统一品牌、小白友好、拿来即用**的方片培训课件。源自《方片 AI 小白实战课》（14 页，奶油底 + 方片黄 + 小老虎老师）。

## 先做三件事

1. **确认主题与受众**：课程名、面向谁（默认"零基础小白"）、要教会的几件事（建议 3–4 个）、每个方法是否有真实截图/案例。
2. **套用品牌**：颜色、logo、字体、IP 严格按本技能；更细的品牌规范（更多 logo 变体、色卡、字体安装包、海报模板）读 `fangpian-brand-kit` 技能。
3. **按"页面蓝图"搭页**：不要自由发挥版式，从 14 页蓝图里挑、按 8 个模块拼。

## 设计基因（硬规则，不要改）

- 画布 16:9（飞书 Slides 960×540；PPT 13.33×7.5in / 1280×720）。
- 底色：**奶油底 `#FFFCF2`**（全部页统一，不用纯白）。
- 主色：**方片黄 `#FFF300`**（强调、编号、标签、金句条文字）。
- 墨色：**暖黑 `#1A1A1A`**（标题、方块、全宽金句条底）；正文用暖灰 `#5A564A`、辅助灰 `#787464`。
- IP 衬底：**浅黄方块 `#FFF0B4`**（放在小老虎背后）；卡片底用白 `#FFFFFF`。
- 字体：中文 **Noto Sans SC / 思源黑体**（标题 Bold、正文 Regular）；亲和标签可用圆体（江城圆体 / ChillReunion）；英文数字用 **Nunito**。
- 每个内页都有**统一页头**：黄色小栏目标签 + 黑色大标题（短句、口语）+ 可选灰色副标题。
- 老虎是"老师"，不是装饰：**每页右侧或信息图角落固定一只按场景选的老虎**，姿势对照表见下。

## 8 个可复用模块（拼版只用这些）

1. **统一页头框**：黄小标签 + 黑色大标题 + 灰副标题。
2. **黄色胶囊**：眉标/栏目名/标签（圆角矩形，黄底黑字）。
3. **黑方块编号**：黑底方片黄数字（01–04），用于"学会几件事"和总结。
4. **黄方块编号**：黄底暖黑数字（1–5），用于步骤流。
5. **黑色全宽金句条**：圆角黑条 + 居中黄字，给每页一句可记忆结论。
6. **白描边卡片**：白底 + 暖黑描边圆角卡，装勾选清单或"痛点/解法"对比。
7. **浅黄底 IP 方块**：右侧固定 `#FFF0B4` 方块 + 一只透明老虎。
8. **整幅品牌信息图**：复杂知识点做成一张统一风格的 PNG 卡片（黄色页眉胶囊 + 编号蓝/黄模块 + 教师虎 + 方片 logo）整幅嵌入，参考 `assets/infographics/`。

## 标准 14 页节奏（可按主题增减，顺序不变）

封面 → 课程地图（学会 4 件事）→ 核心认知（1 个比喻/纠偏）→ 每个方法（是什么→为什么→现场演示→好习惯，每方法 2–3 页）→ 总结回顾（4 件事）→ 行动清单（回去先做 3 件事）→ 金句收尾。

逐页模块组合、版式比例和示例文案见 `references/page-blueprints.md`。

## 制作流程（落到飞书 Slides / PPT）

1. 先定课程骨架：课程名 + 一句 slogan + 学会的 N 件事 + 每个方法的演示案例与截图。
2. 复杂知识点先产出整幅信息图（仿 `assets/infographics/` 的卡片样式：黄胶囊页眉、编号模块、教师虎、logo）；操作类内容直接截真实软件界面图。
3. 用飞书 slides 技能逐页搭：页头/清单/卡片用**原生可编辑形状**（便于改），信息图与老虎用**透明 PNG**（老虎不要白底，用 `assets/tigers/` 已抠图）。
4. 每一页落一句金句（黑条黄字）；封面和收尾各一只招手虎，行动页用点赞虎。
5. 自检：每页有页头、右侧或角落有虎、颜色只用规定色板、正文不堆字、截图能看清、结论口语化。

## 内容口径（小白友好的关键）

- 全程口语："把活儿说清楚，让 AI 替你干""今天咱学会这 4 件事"，不堆术语。
- 数字口诀：**4 件事 / 3 件事 / 5 个零件**，好记；每步一动词短句。
- 每个方法必须有**真实界面截图 + 可点链接/下载地址**，让人当场能做。
- 讲完立刻给"今晚就能做"的行动清单。
- 详细写作法与示例见 `references/content-method.md`。
