## 一、品牌色板

| 色彩 | HEX | RGB | CMYK | 用途 |
|---|---|---|---|---|
| 方片黄（主色） | `#FFF300` | 255 / 243 / 0 | 8% / 1% / 86% / 0 | 大面积品牌背景、黑底上的强调字、主视觉 |
| 黑 | `#000000` | 0 / 0 / 0 | 93% / 88% / 89% / 80% | 文字、深色背景、与黄搭配的高对比 |
| 金属银 | 约 `#D1D1D1`（渐变） | 209 / 209 / 209 | — | 高端/质感背景、年会等正式场合 |
| 子品牌紫 | `#8A66FA` | 138 / 102 / 250 | — | 方片时尚、方片家居专属 |

- 取色以 `assets/colors/` 下官方色卡为准：`bg-yellow.png`（纯黄）、`bg-black-and-silver.png`（黑+银）、`bg-silver.png`（银渐变）。
- 主组合：**黑底黄字 / 黄底黑字 / 黑黄对半**。紫色只出现在时尚、家居赛道，母品牌物料不使用紫。
- 黄色必须保持高饱和明亮，禁止压暗、偏橙、偏绿。

## 二、标识图形（Logo）

主字标是书法手写体「方片」两个大字，下方是字距拉开的英文 `FANG PIAN`。透明底 PNG 共三色，在 `assets/logos/`：

| 文件 | 字色 | 适用背景 |
|---|---|---|
| `logo-fangpian-black.png` | 黑 | 白底、黄底、浅灰底、任何浅色 |
| `logo-fangpian-yellow.png` | 黄 | 黑底、深色照片/深色渐变 |
| `logo-fangpian-white.png` | 白 | 黑底、深色底、复杂深色照片 |

使用规则：
- 必须用官方透明文件，**不得**用书法字体自己拼「方片」、不得描边/换色/加投影/拉伸/压扁/旋转。
- 最小使用尺寸：屏幕端字标宽不低于 88px，印刷端不低于 20mm，保证笔触不糊。
- 安全区：字标四周留白 ≥ 「片」字笔画高度；安全区内不压字、不压图。
- 深色照片上若黄字不清晰，改加纯色黑/黄色块再放字，不做半透明叠底。

## 四、标准字体

| 字体 | 字重数 | 斜体 | 类型 | 用途 |
|---|---|---|---|---|
| `misan`（字体包 misan.zip） | 10 | 无 | 黑体 | 正文、常规信息、说明文字主力 |
| `pop`（pop.zip） | 16 | 有 | 黑体 | 大标题、强调、需要斜体时 |
| `江城圆体`（江城圆体.zip） | 6 | 无 | 圆幼 | 亲和活泼：母婴、生日会、员工、新人 |
| `字体圈欣意冠黑体`（.ttf） | 1 | 无 | 艺术体 | 主标题、数字、视觉焦点 |

- 英文/数字标准字族：`DIAMOND NEWMEDIA`（多字重，见 `assets/fonts/preview-en.png`）。
- 中文标准字稿与字重见 `assets/fonts/preview-cn.png`。
- 品牌 Slogan：**「快速创新　无限成长」**（快速创新与无限成长之间留空格，正常排两行）。
- 字体安装文件（.zip/.ttf）存于公司设计部字体库，不在本技能内；缺失时向设计部索取，**不得用未授权字体替代**。
- 层级建议：主标题用 欣意冠黑体/pop；副标题用 pop 或 misan；正文与信息用 misan；员工向亲和物料用江城圆体。

## 六、背景与安全区

- 标准背景：纯黄 `#FFF300`、纯黑 `#000000`、银渐变；白底细文海报也可。
- 黄底用黑字黑 logo；黑底用黄/白字；银/浅底用黑字。
- 照片上压字时，加纯色或半透明黑色块保证对比，不直接把黄字放在杂乱画面上。
- logo 与 IP 周围留安全区，避免贴边、被裁切、被其它元素触碰。
