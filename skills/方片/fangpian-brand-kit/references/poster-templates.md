## 二、用模板做图的正确方式

日常需求 90% 是**换文字、换颜色、换素材**，不要重排版：

1. 打开对应 `.ai`，先「另存为」新文件，不动源文件。
2. 换字：双击文字框替换文案，字体保持模板所用授权字体（见品牌规范）。
3. 换色：用吸管吸取模板或色卡里的官方黄/黑/银/紫，不要手动调色。
4. 换素材：把新素材抠成透明 PNG（见下文），替换蒙版里的图，保持比例不变形。
5. 放 logo / IP：从本技能 `assets/` 取透明文件，按安全区放置。
6. 导出：屏幕传播导出 PNG（RGB）；印刷导出对应 CMYK 并嵌入字体。

## 三、Adobe Illustrator（AI）快速上手

> 这里的 AI 指 **Adobe Illustrator**，不是人工智能。推荐 Adobe Illustrator 2022。

**基础操作（Mac 把 Ctrl 换成 Command）**

- 复制 Ctrl+C / 粘贴 Ctrl+V / 剪切 Ctrl+X / 撤销 Ctrl+Z / 保存 Ctrl+S / 编组 Ctrl+G
- 按住 Alt 拖动元素 = 复制；按住 Shift 拖动 = 水平/垂直移动；Shift+Alt 拖动 = 水平/垂直复制
- 按住 Alt 缩放 = 以中心缩放；按住 Shift 缩放 = 等比缩放；Shift+Alt = 中心等比缩放
- Alt+滚轮 = 缩放画面；空格+鼠标拖拽 = 移动画布

**选择工具（V）**：选中后四周出现小白块；移到白块周围可旋转；按住白块拖动缩放（等比按 Shift）；按住元素本体移动。

**文字工具（T）**：单击空白处加字；退出按 Esc 或点选择工具；上方工具栏改字号/字体；双击文字可改；Shift 多选后右键「编组」可当整体移动；直接选择工具可击穿编组编辑单个元素，右键取消编组 Ctrl+Shift+G。

**剪切蒙版（Ctrl+7）**：上层形状 + 下层内容，框选两个元素后右键「建立剪切蒙版」（或 Ctrl+7）；双击进入蒙版可替换内部元素；「释放剪切蒙版」可取消，注意释放后上层形状会以透明形式保留，需选中删除。

**颜色调整**：选中元素，双击左侧色块弹出调色盘；调色盘为 RGB 模式，左右控制灰白度、上下控制明暗、右侧色条直接换色；可按 Shift 用吸管精准吸取官方色。

## 四、抠图教程（创客贴 / 醒图）

需要无背景 PNG（放人物、IP 以外的素材）时使用。

**创客贴（网页版）**

1. 浏览器搜索「创客贴」，点带官方标识的链接进入。
2. 右上角登录（找毛姐/晗姐/若男扫码，截图二维码发微信/飞书）。
3. 主页左下角选「智能抠图」进入。
4. 上传需要抠图的素材。
5. 抠完点右上角「下载」，即得无背景 PNG。

**醒图（手机 App）**

1. 打开醒图 → 点「智能抠图」。
2. 插入人物图片 → 点「智能抠图」。
3. 绿色区域是选择范围，用画笔/橡皮擦调整。
4. 背景去除后即为抠图效果。
5. 右上角「导出」，得到无背景 PNG。

> 方片 IP 老虎本身已是透明 PNG（在 `assets/ip/`），无需再抠。
