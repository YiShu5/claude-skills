# 方片品牌形象库（FANG PIAN Brand Kit）

本技能是方片新媒体的**品牌视觉单一事实来源**。做任何视觉物料前，先加载本规范，再从 `assets/` 直接取用现成素材，禁止凭空重画 logo、重配颜色、替换字体或乱换 IP。

## 资产目录

- `assets/logos/` — 透明底「方片」字标（黑/黄/白三色）与母品牌、赛道子品牌标准组合（lockup）
- `assets/colors/` — 黄 / 黑 / 银官方背景色卡（取色、对色用）
- `assets/ip/` — 方片老虎 IP 透明底素材，按场景命名（01–20）
- `assets/fonts/` — 中英文标准字体预览（字体安装文件需向设计部门索取，见 references）

## 硬性品牌规范（不可违反）

1. **Logo 用官方文件，不许重绘**：字标是书法手写体「方片」+ 下方字距拉开的 `FANG PIAN`。只能从 `assets/logos/` 取透明 PNG，按背景选颜色：
   - 浅色/白/黄底 → `logo-fangpian-black.png`（黑字）
   - 黑底/深色底 → `logo-fangpian-white.png`（白字）或 `logo-fangpian-yellow.png`（黄字）
   - 黄底用黑字。禁止拉伸、压扁、加阴影、描边、旋转、改字、换书法字体。
   - 四周留足不小于「片」字笔画高度的安全区，安全区内不压文字、不放别的图形。
2. **配色只用官方色板**：
   - 主色 **方片黄 `#FFF300`（RGB 255/243/0，CMYK 8/1/86/0）**
   - 黑 `#000000`、金属银（银色渐变，取色见 `assets/colors/bg-silver.png`，约 `#D1D1D1` 一带）
   - 子品牌紫 `#8A66FA`（RGB 138/102/250）用于**方片时尚、方片家居**
   - 经典高对比组合是「黑 + 黄」「黑底黄字」；黄色是大面积品牌色，不要把它降成暗黄或橙黄。
3. **字体只用授权的四款**，不要用系统默认黑体或免费字体替代：
   - `misan`（黑体，10 字重）——正文/常规信息主力
   - `pop`（黑体，16 字重，含斜体）——强调、大标题
   - `江城圆体`（圆幼，6 字重）——亲和、活泼、母婴/生日/员工向
   - `字体圈欣意冠黑体`（艺术体）——数字、主标题、视觉焦点
   - 英文/数字走 `DIAMOND NEWMEDIA` 一套字重（见 `assets/fonts/preview-en.png`）。品牌 Slogan：**「快速创新　无限成长」**。
4. **IP 老虎用现成透明图，按场景选姿势**：3D 黄色小老虎是方片 IP，**不要自己重画或改色**。从 `assets/ip/` 选与语义匹配的姿势（选图对照见 [references/brand-identity.md](references/brand-identity.md)）。IP 同样留安全区，不被裁切到脸、尾巴、手持物。
5. **子品牌用对应 lockup**：母婴用 `lockup-muying.png`（黄底黑字）、时尚用 `lockup-shishang.png`（紫底白字）、家居用 `lockup-jiaju.png`（白底紫字）、集团口径用 `lockup-xinmeiti.png`。给某赛道做物料，必须用该赛道 lockup，不要混用。

## 做物料的标准流程

1. **定类型**：对照 [references/poster-templates.md](references/poster-templates.md) 找到最接近的部门模板与画布比例（入职/周年/生日/培训会/线上课/博主签约/股东积分/大事件水印/灯箱）。有现成 `.ai` 模板就「换字、换色、换素材」，不要另起炉灶。
2. **定主体**：是集团还是某赛道（母婴/时尚/家居），决定用哪套 logo 和配色。
3. **摆 logo**：放在固定角位（多为左上或右上），给安全区，按背景选字标颜色。
4. **选 IP 姿势**：按场景语义选 `assets/ip/` 对应图（如培训会用 `04-teacher`，签约用 `08-money` 或 `12-ok`，生日会用 `07-boba-cake`，短视频用 `18-clapperboard`）。
5. **排字**：用四款授权字体，建立「主标题（艺术/pop）→ 副标题（misan）→ 时间地点等信息（misan）」层级；正文不用书法字。
6. **收尾检查**：颜色取色与色卡一致；logo/IP 没变形、没被裁；安全区干净；无错别字；导出 PNG（屏幕用）或按模板交付。

## 生成式 AI 配图时的品牌约束

- 数字人、插画、封面若需要主视觉，主色、氛围围绕黑/黄（赛道用紫）；需要吉祥物时，描述为「方片 3D 黄色小老虎 IP」并优先复用 `assets/ip/` 现成图，而非让模型另画一只老虎。
- 生成画面的风格要与 IP 的 3D 质感、圆润造型统一，避免写实、暗黑、低龄或赛博风冲突。
