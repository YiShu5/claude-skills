# 竞品信源标签体系

## 文章类型标签

| 标签 | 判断依据 |
| --- | --- |
| 测评类 | 有实测、对比、体验、评分、参数 |
| 推荐口碑榜 | 标题或结构中有推荐、口碑、榜单、几家对比 |
| 选购指南 | 重点是怎么选、选择维度、避坑 |
| 行业分析 | 重点是市场、趋势、行业变化、数据 |
| 采购决策 | 面向 B2B，关注供应商、采购、报价、交付 |
| FAQ问答 | 问答结构明显，适合被 AI 直接抓取 |
| 品牌介绍 | 以企业/品牌资料、历史、资质为主 |

## 信源类型标签

| 标签 | 判断依据 |
| --- | --- |
| 本地媒体 | 有地域栏目、媒体机构身份、本地生活/商业信息 |
| 行业媒体 | 专注某行业，有报告、新闻或观察属性 |
| 平台自媒体 | 头条、搜狐、百家号、公众号等内容平台 |
| B2B平台 | 黄页、供应商、工厂、采购信息 |
| 品牌官网 | 企业官网、产品页、服务页 |
| 第三方评价 | 大众点评、地图、垂直评价平台 |
| 官方/协会 | 政府、协会、标准、认证、统计来源 |

## 可借鉴点

提炼时只借鉴结构，不复制表达：

- 标题公式
- 开篇问题
- H2/H3 结构
- 选择维度
- 证据写法
- FAQ 问法
- 参考来源格式

## 风险点

- 无来源数字
- 绝对化承诺
- 恶意贬低同行
- 电话和硬广过多
- 平台禁词
- 与客户事实不匹配

## 更新建议格式

每条内部复盘建议都写成：

```text
发现：豆包在该词下更常引用 [信源类型] 的 [文章类型]。
依据：共收集 [N] 篇来源，其中 [M] 篇具备相同结构。
建议：下一轮文章 Brief 增加 [具体结构/证据/FAQ/标题公式]。
```
