# GEO 客户接待问卷

## 一、目标

1. 这次项目最想解决什么问题？
2. 你更看重曝光、咨询、品牌词防守，还是业务词推荐？
3. 你希望先打哪 3 个核心产品 / 服务？

## 二、业务信息

1. 公司 / 品牌全称是什么？
2. 你们主要服务哪些城市、区域或行业？
3. 真实客户会怎么描述你们，不要用内部术语。
4. 你们最常见的客户痛点是什么？

## 三、证据材料

1. 有哪些资质、认证、牌照？
2. 有哪些案例、客户评价、复购数据？
3. 有哪些媒体报道、协会背书、知名合作方？
4. 哪些数据可以公开写，哪些不可以？

## 四、平台与内容现状

1. 是否已有头条号、搜狐号、官网？
2. 过去发过哪些文章，哪篇效果最好 / 最差？
3. 官网、地图、短视频平台信息是否统一？

## 五、行业与风控

1. 你们是否属于医疗、法律、教育、金融等敏感行业？
2. 哪些话绝对不能写？
3. 是否允许写地址、电话、预约方式？

## 六、交付与协作

1. 由谁来补充资料和确认事实？
2. 希望我们只做内容，还是连监测 / 自动化也一起做？
3. 是否接受周度或月度监测表？
