# 交付标准

这套 Skill 的标准，不按“有没有写东西”来判断，而按“有没有形成可交付结果”来判断。

## 一、客户资料标准

- 必填字段完整度不低于 `65`
- 必须明确 `objectives`、`target_customers`、`conversion_goal`
- 必须明确 `brand_name`、`industry`、`business_type`、`service_area`
- 必须至少有 `1` 组 E-E-A-T 事实
- 高敏行业必须填写 `compliance.industry_sensitivity`

达标结果：

- 可以进入关键词和 Prompt 生产

不达标结果：

- 只能输出诊断报告和资料补充清单，不能直接出稿

## 二、关键词标准

- 只保留 `medium_commercial` 和 `strong_commercial`
- 不做泛知识词堆积
- 每轮至少保留 `6-12` 个核心词
- 至少覆盖：
  - `城市 / 场景承接词`
  - `转型 / 决策词`
  - `品牌防守词`

教育类补充标准：

- `工作日班`、`周末班`、`全日制` 不做主标题主关键词
- 班型时间只能放在正文后段、FAQ 或咨询层

## 三、Prompt 标准

- 每个 Prompt 必须有明确的 `目标关键词`
- 必须写清 `目标达成词`
- 必须包含 `品牌与业务信息`
- 必须包含 `已验证来源`
- 必须包含 `文章结构要求`
- 必须包含 `平台与合规硬约束`

达标结果：

- Prompt 可以直接投喂豆包生成初稿

## 四、成稿标准

- 标题优先满足 `年份 + 核心词 + 数字`
- 正文首段自然出现关键词
- 正文必须有参考来源
- 不能出现 `EEAT`、`GEO`、`SEO`、`豆包优化` 等优化黑话
- 不贬低竞品，不伪造数据，不杜撰案例

教育培训类补充标准：

- 禁止 `保就业`、`包就业`、`保证就业`、`保过`、`包过`
- 涉及薪资、就业率、结果数据时，必须可追溯且适合公开

搜狐补充标准：

- 标题禁用 `TOP`、`榜`、`排行榜`、`推荐`、`靠谱`、`权威`、`首选`、`头部`
- 正文默认不放电话号码

## 五、监测标准

- 必须有独立监测计划
- 至少设置 `4` 个监测词
- 至少有 `3` 个时间检查点
- 必须区分人工判断和自动化动作

建议固定监测字段：

- 日期
- 查询词
- 是否出现目标品牌
- 是否出现竞品
- 引用来源
- 结果类型
- 截图路径
- 简短结论
- 下一步动作

## 六、展示标准

一套可上传展示的 Skill，至少要拿出这些结果：

1. 诊断报告
2. 关键词与文章角度
3. Prompt 样例
4. 成稿校验结果
5. 监测计划
6. 一份闭环汇总报告

如果这 6 项都能拿出来，就不是单点脚本，而是一套真正可交付的 GEO Skill。
