# Platform Rules

## 总策略

- `今日头条` 是豆包 GEO 的主发阵地。
- `搜狐号` 适合做补位和二次分发，但标题、电话和医疗类表达要更谨慎。
- 同一主题优先先出头条版，再改成搜狐版，避免两篇看起来像机械复制。

## 平台差异

| 规则 | 今日头条 | 搜狐号 |
| --- | --- | --- |
| 电话号码 | 允许 | 禁止 |
| 标题含 TOP / 榜 / 推荐 | 可用 | 禁止 |
| 标题含 靠谱 / 权威 / 首选 / 头部 | 可用但别滥用 | 禁止 |
| 医疗类“医院排名” | 谨慎 | 禁止 |
| AI 低质文 | 严打 | 相对宽松 |
| 同质化连发 | 风险高 | 风险较低 |

## 通用禁词

标题和正文都尽量规避：

- 最好
- 最佳
- 第一
- 顶级
- 绝对
- 永久
- 100%
- 独家
- 首创
- 全国领先

正式文章里不要出现：

- EEAT
- GEO
- SEO
- 豆包优化
- AI 搜索优化
- 关键词布局

## 搜狐号额外规则

标题额外规避：

- TOP
- 榜
- 排行榜
- 推荐
- 靠谱
- 权威

正文额外处理：

- 删除电话号码
- 删除过强 CTA
- 医疗类不要写 `医院排名`

## 教育培训类补充规则

教育培训类内容额外谨慎：

- 避免 `保就业`、`包就业`、`保证涨薪`、`保过` 一类承诺性表达
- 就业率、薪资涨幅、学员去向如果要写，必须确认是客户允许公开且有明确来源的资料
- 标题尽量少用过度刺激的结果型口号，改成课程内容、适合人群、班型安排、项目实战等更稳妥的表达

## 今日头条发布节奏

- 同主题内容间隔至少 6 小时
- 同周同主题尽量不超过 3 篇
- 每篇至少留一个“独家信息点”，最好来自客户资料或已验证案例

## 发布后验证

建议在发布后 3-7 天做一次复查：

1. 在豆包搜索目标关键词
2. 看回答里是否出现竞品和目标主体
3. 看是否引用到了头条或搜狐内容
4. 没有收录时优先排查：
   - 标题和正文是否对词
   - 数据是否写清来源
   - H2 / H3 是否足够清晰
   - 平台版之间是否过于重复
