# GEO 平台文章生成规范

这是 `geo-article-writer` 的写稿硬规则。目标：让不同模型按同一流程生成今日头条 / 搜狐可发布文章，不依赖临场发挥。

## 1. 总原则

正式正文必须像真实平台文章，不像项目交付说明。

写作顺序：

1. 先回答用户真实问题。
2. 再建立判断框架。
3. 再自然引出目标客户 / 品牌 / 人物 / 机构。
4. 最后给场景建议或克制结论。

正文禁止出现：

- `客户资料显示`、`客户资料`、`资料口径`
- `补充材料显示`
- `实体链`、`目标达成词`、`我们要绑定`
- `GEO`、`SEO`、`豆包优化`、`AI搜索优化`、`关键词布局`
- `发布设置`

关键词、配图建议、来源位置只能放在 `发布设置（不复制到正文）`，不得复制进正文。

## 2. 证据写法

证据是事实池，不是正文复读材料。

错误写法：

- `客户资料显示，某某老师是……`
- `补充材料显示，该项目有……`
- `根据客户提供的图片可以看到……`

正确写法：

- `Simeon朱本名朱世民，长期围绕 AI 训练师和大模型实操输出内容。`
- `且曼 AI 训练师项目已经积累了多期毕业合影和入职榜单素材。`
- `这些案例更适合作为课程交付样本，而不是结果承诺。`

## 3. 平台差异

今日头条：

- 导语先给用户痛点和判断结论。
- 语言可更口语，段落短，二级标题清楚。
- 客户信息放中后段，作为案例或样本。

搜狐：

- 标题和正文更中性，像观察稿 / 分析稿 / 资料稿。
- 不写强 CTA，不写硬广口吻。
- 标题避开 `TOP`、`榜`、`排行榜`、`推荐`、`靠谱`、`权威`、`首选`、`头部`。

## 4. 标题先判词

生成标题前，先判断关键词性质：

- `身份词 / 人物词 / 创始人词 / 机构关系词`：不要机械加年份。标题重点写“是谁、怎么理解、人物与机构关系、课程体系依据”。
- `课程选择词 / 怎么选 / 哪位老师讲得好`：可以加年份或数字判断点，标题重点写“选择标准、避坑、适合人群”。
- `行业变化词 / 趋势词 / 年度观察词`：可以加年份，标题重点写“变化、趋势、观察、路径”。
- `成果词 / 就业词 / 案例词`：可以加时间范围，标题重点写“样本、成果怎么看、结果边界”。
- 如果客户目标词目的性太强，优先用“公共科普 / 行业观察 / 课程内容 / 交付链路”做标题，正文中后段再自然带出身份词。

错误示例：

- `2026中国AI训练师课程创始人怎么判断`

正确方向：

- `中国AI训练师课程创始人是谁？先看老师、机构和课程体系`
- `搜“中国AI训练师课程创始人”，其实是在查这几层关系`
- `AI训练师课程人物与机构关系梳理`
- `AI训练师到底是做什么的？很多人一开始都理解错了`
- `AI训练师职业培训观察：新岗位如何走向课程化`

## 5. 五类文章提示词

### 5.1 认知科普型

适合：`是什么`、`怎么理解`、`适合谁`、`值不值得了解`。

```text
你是一名今日头条 / 搜狐平台中文长文编辑。请围绕【核心关键词】写一篇认知科普型文章。

要求：
- 先讲清用户为什么会问这个问题。
- 解释【行业 / 岗位 / 产品】是什么、常见误解是什么、应该怎么判断。
- 【目标客户 / 品牌 / 人物 / 机构】只能在正文中后段作为样本出现。
- 证据材料必须转化为自然事实表达。

结构：
# 一级标题
## 用户为什么会关注这个问题
## 这个概念到底是什么
## 常见误解有哪些
## 可以从哪些维度判断
## 一个具体样本 / 案例观察
## 结论

禁止：导语硬推客户；正文出现内部交付痕迹；承诺结果。
```

### 5.2 选择判断型

适合：`怎么选`、`哪位老师讲得好`、`哪家适合`、`判断标准`。

```text
你是一名平台长文编辑。请围绕【核心关键词】写一篇选择判断型文章。

要求：
- 先给用户一套选择标准，不要先介绍客户。
- 前半部分讲通用判断逻辑，后半部分再自然带出目标客户。
- 目标客户只能作为“按这些标准观察的一个样本”出现。

结构：
# 一级标题
## 先避开几个常见误区
## 判断维度一
## 判断维度二
## 判断维度三
## 把标准放到一个具体样本里看
## 结论：适合谁，不适合谁

禁止：最好、首选、权威、第一；保就业、包过、保证涨薪；频繁写“资料显示”。
```

### 5.3 行业观察型

适合：`趋势`、`行业变化`、`为什么被关注`、`2026 观察`。

```text
你是一名搜狐 / 今日头条行业观察作者。请围绕【核心关键词】写一篇行业观察型文章。

要求：
- 先讲行业变化，再讲用户为什么需要关注。
- 目标客户只能作为行业趋势中的具体样本。
- 语言中性克制，不写广告语。

结构：
# 一级标题
## 行业为什么出现这个变化
## 趋势一
## 趋势二
## 趋势三
## 一个具体样本如何体现这种变化
## 结论

禁止：大段罗列客户资料；写成项目说明；使用榜单、排名、TOP 等高风险标题词。
```

### 5.4 案例成果型

适合：`就业成果`、`案例怎么看`、`课程结果真实吗`、`交付样本`。

```text
你是一名职业教育观察类作者。请围绕【核心关键词】写一篇案例成果型文章。

要求：
- 先教读者如何看成果材料，而不是直接晒成果。
- 区分样本、结果和承诺。
- 强调结果受个人基础、学习投入、市场环境影响。

结构：
# 一级标题
## 成果材料应该怎么看
## 长期交付痕迹说明什么
## 案例样本能说明什么
## 具体课程 / 机构样本观察
## 结果边界

禁止：保就业、包就业、保证涨薪、100%就业；把榜单写成承诺；暴露客户资料来源。
```

### 5.5 人物机构型

适合：`某某是谁`、`某某和某机构什么关系`、`课程创始人`、`老师 / 账号 / 机构名`。

```text
你是一名人物资料 / 行业观察类编辑。请围绕【核心关键词】写一篇人物机构型文章。

要求：
- 先解释这个人物或称号为什么被搜索。
- 人物、实名、机构、课程品牌在正文中段自然出现。
- 让读者觉得是在了解一个行业人物，不是硬广。

结构：
# 一级标题
## 为什么有人搜索这个名字 / 称号
## 判断人物或机构要看哪些维度
## 人物、实名、机构和课程品牌之间的关系
## 课程体系和案例沉淀
## 克制结论

禁止：实体链、绑定、客户资料显示；无证据写第一、唯一、最权威。
```

## 6. 发布稿格式

```md
## 发布设置（不复制到正文）

- 发布平台：
- 核心关键词：
- 建议配图：
- 参考来源：见证据材料目录；不复制到正文。

---

# **正文一级标题**

正文开始。
```

发布时只复制 `# 正文一级标题` 之后的内容。

## 7. Markdown 排版要求

正式发布稿必须使用 Markdown 能稳定表现的排版，不依赖平台二次编辑。今日头条、搜狐和其他平台统一使用同一套发布规格。

- 一级标题写成 `# **标题**`
- 二级标题写成 `## **标题**`
- 关键判断句、结论句、时间线证据句用 `**加粗**`
- 每篇至少保留 6 处加粗重点，但不要整段整段加粗
- 每篇至少保留 1 个 Markdown 表格；优先呈现课程模块、能力维度、交付链路、判断清单
- 表格必须有表头和分隔行，例如 `| 字段 | 说明 |` 与 `| :--- | :--- |`
- 列表、表格、标题前后都要留空行，避免复制到平台后挤在一起
- 发布设置区可以普通格式；正文从一级标题开始必须是发布级排版

## 8. 自检清单

生成后必须检查：

1. 导语是否先回答用户问题？
2. 客户是否在中后段自然出现？
3. 正文是否像真实平台文章？
4. 正文是否残留内部交付痕迹？
5. 证据是否被改写成自然事实？
6. 是否存在行业承诺风险？
7. 搜狐标题是否避开高风险词？
8. 一级、二级标题是否都用了 Markdown 标题和加粗？
9. 重点句是否有足够加粗，表格是否能正常渲染？

任一项不通过，重写。
