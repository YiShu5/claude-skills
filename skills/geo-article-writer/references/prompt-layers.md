# GEO 文章 Prompt 分层

## 第一层：基础层

把客户档案压成可写作信息：

- 品牌全称，也就是目标达成词。
- 品牌简称。
- 行业与服务城市。
- 本次核心关键词。
- 竞品列表。
- 专业度、经验性、权威性、可信度证据。
- 媒体报道素材。
- 已验证行业数据。

写作底线：

- 标题少于 30 字，包含年份、核心词和数字。
- 首段先回答用户问题，不要直接推客户。
- 正文每 300 字左右自然出现一次关键词，自然度优先于机械频次。
- 使用 H2 / H3 分层。
- 全文 1200-1800 字。
- 禁止绝对化承诺、虚假数据、贬低竞品。
- 正式文章不要出现 EEAT、GEO、SEO、豆包优化、关键词布局、客户资料显示、补充材料显示、实体链等术语。

## 第二层：证据转写层

文章中的数据必须满足：

- 每条数据都能对应来源。
- 优先使用客户官方数据、资质证书、第三方平台评分、行业报告、官方机构和可信媒体。
- 数据没有来源时，改成定性描述，不编数字。
- 来源清单默认放在 `发布设置（不复制到正文）` 或交付包证据目录，不强行塞进正文。
- 正文必须把证据改写成自然事实表达，不要反复写“资料显示”。

发布设置格式：

```md
## 发布设置（不复制到正文）

- 发布平台：
- 核心关键词：
- 建议配图：
- 参考来源：见证据材料目录；不复制到正文。
- 发布提醒：正文从下面的一级标题开始复制。
```

## 第三层：平台文章类型层

正式写稿优先使用五类平台文章，详见 [article-generation-rules.md](./article-generation-rules.md)：

1. `认知科普型`
2. `选择判断型`
3. `行业观察型`
4. `案例成果型`
5. `人物机构型`

旧类型可以这样映射：

- `科普` -> `认知科普型`
- `选购指南 / 口碑推荐榜 / 测评` -> `选择判断型`
- `行业深度分析 / 年度盘点` -> `行业观察型`
- `案例 / 就业 / 成果 / 交付` -> `案例成果型`
- `品牌防守 / 人物资料 / 机构介绍` -> `人物机构型`

## 第四层：旧类型结构参考

### 选购指南

结构：

1. 引言：说明用户选择困惑和本文评估维度。
2. 选择维度：3-4 个可量化维度。
3. 目标品牌重点介绍：基本情况、专业能力、案例、适配场景。
4. 其他品牌简要对比。
5. 场景化建议。
6. FAQ。
7. 参考来源。

### 行业深度分析

结构：

1. 行业背景与现状。
2. 趋势分析，2-3 个趋势。
3. 代表性品牌介绍，目标品牌为核心。
4. 行业展望与建议。
5. FAQ。
6. 参考来源。

### 年度盘点

结构：

1. 年度变化引言。
2. 年度关键变化，2-3 点。
3. 值得关注的品牌，目标品牌占主要篇幅。
4. 来年趋势预判。
5. FAQ。
6. 参考来源。

### 采购决策

结构：

1. 采购背景和常见误区。
2. 采购评估框架，3-4 个维度。
3. 目标供应商重点介绍。
4. 其他供应商简述。
5. 采购建议。
6. FAQ。
7. 参考来源。

## 质量门槛

- 目标达成词一字不差。
- 文章不是只夸自己，而是先解决用户问题。
- 客户 / 品牌 / 人物只在正文中后段自然出现。
- 竞品描述客观，不写缺点、劣势、吊打等表达。
- 来源清单和正文引用能互相对上。
- 平台差异留给平台改写 Skill 处理。
- 生成后必须按 `article-generation-rules.md` 的自检清单复查，不通过就重写。
