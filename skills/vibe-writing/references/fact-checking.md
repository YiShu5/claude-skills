# Fact Checking

Classify claims before deciding whether to use, research, qualify, or remove
them. Keep voice evidence separate from factual evidence.

## Claim States

Use exactly these working states:

| State | Treatment |
|---|---|
| confirmed author fact | Use only when the author has confirmed the experience, identity, achievement, project result, quotation, or other personal fact. |
| stable general fact | Use directly only when it is established, noncontroversial, and unlikely to have changed. |
| time-sensitive external fact | Research current authoritative sources before use. |
| unverified or unverifiable claim | Delete it, qualify it, or flag it for confirmation; never present it as established. |

## Verification Rules

Require author confirmation before using first-person experience, identity,
private project details, or achievements. A prior draft or memory may reveal a
candidate claim, but it does not supply that confirmation.

For a requested first-person story containing any such claim, use this gate:

1. Look for explicit factual confirmation separate from the writing premise.
2. Treat the premise itself, including wording such as “写我……”, as unconfirmed.
3. When confirmation is absent, stop and return exactly one focused question
   asking whether the claim is true and may be used. Draft only after a yes.

If the claim can be omitted, remove it instead of presenting it as autobiography.

Research current authoritative sources for products, versions, prices, policies,
news, and statistics. Prefer official or primary sources, then credible
professional sources. Use community material to describe reported opinions or
experiences, not as a substitute for factual verification.

Treat any fact that may have changed as time-sensitive even when an older source
looks plausible. Record the source date when recency affects interpretation.

Memory is context, not an external factual source. Do not cite or rely on
ChatGPT memory, a voice profile, or model recall as proof of an external claim.

## Failure Handling

When verification is unavailable or conflicting, choose one of these actions:

- Delete the claim when it is not essential.
- Qualify the wording to match what the evidence supports.
- Flag the item as unverified and request confirmation when it is essential.
- Attribute disagreement when reliable sources genuinely conflict.

Do not invent a number, quote, case, link, or source to complete a draft. Do not
block unrelated, supported parts of the task.

## Output

Keep source notes proportionate to the request. Distinguish verified facts,
author-confirmation items, and unresolved claims clearly enough for the user to
act, but do not add a research dossier when the task only needs a concise note.
