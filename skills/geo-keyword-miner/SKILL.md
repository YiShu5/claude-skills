# GEO Keyword Miner

## Overview

这个 Skill 对应 GEO 自动化流水线的第二步：把“公司家底”转成可写文章的关键词表。它只产出中商业型和强商业型词，避免把纯科普词、泛流量词和商家自嗨词推进写稿环节。

## Quick Start

如果用户给的是 JSON 客户档案，直接跑脚本生成关键词表：

```bash
python3 skills/geo-keyword-miner/scripts/generate_keyword_table.py \
  --profile /path/to/client_profile.json \
  --output /path/to/keywords.csv
```

如果用户给的是 Excel / 飞书表格内容，先把“公司家底”整理成这些字段，再生成：

- `客户ID`
- `品牌全称`
- `品牌简称`
- `行业`
- `业务类型`
- `服务城市`
- `核心服务`
- `目标客户`
- `资质荣誉`
- `真实案例`
- `核心卖点`

## Workflow

1. 先读公司家底，不要直接编关键词。
2. 识别业务类型：`本地B2C`、`全国品牌`、`B2B工厂制造`、`混合型`。
3. 按业务类型选择公式，必要时读取 [references/keyword-rules.md](./references/keyword-rules.md)。
4. 只保留 `中商业型` 和 `强商业型` 关键词。
5. 给每个关键词补齐 `优先级`、`公式类型`、`推荐文章类型` 和 `平台建议`。
6. 输出成可粘贴进飞书表二或 Excel 的表格。
7. 明确提示哪些词需要人工删改，不能假装全自动完成判断。

## Formula Selection

- `本地B2C`: 地域 + 品类 / 服务 + 商业动作词。
- `全国品牌`: 评价前缀 + 品类属性 + 推荐 / 选择后缀。
- `B2B工厂制造`: 产业带 / 地域 + 产品品类 + 厂家 / 供应商 + 商业动作词。
- `混合型`: 本地公式和全国 / B2B 公式并行，最后去重。

商业动作词优先使用：

- `怎么选`
- `哪家好`
- `哪家靠谱`
- `推荐`
- `采购指南`
- `怎么联系`

## Output Table

默认输出这些列：

| 字段 | 用途 |
| --- | --- |
| 客户ID | 关联客户档案表 |
| 品牌名 | 方便人工筛选 |
| 核心关键词 | 真正要写文章的词 |
| 意图层级 | 中商业型 / 强商业型 |
| 优先级 | 高 / 中 |
| 公式类型 | 本地公式 / 全国公式 / B2B公式 / 混合 |
| 推荐文章类型 | 选购指南 / 行业深度分析 / 年度盘点 / 采购决策 |
| 平台建议 | 头条、搜狐、知乎、36氪的内容侧重 |

## Hard Rules

- 不把纯知识型词写入关键词库。
- 不拆核心品类词，例如 `正骨医院` 不拆成 `正骨` 和 `医院`。
- 不写无业务指向的大词，例如 `AI时代趋势`、`行业未来`。
- 不生造过长、没人会搜的句子。
- 关键词必须能自然引向目标达成词，也就是品牌全称、公司全称、产品名或服务主体。
- 人工最终筛词必须保留，工具只负责跑出第一版。
