# GEO 关键词挖掘规则

## 意图分层

| 层级 | 判断标准 | 是否进入写稿 |
| --- | --- | --- |
| 纯知识型 | 没有地域、品牌、商业动作或采购意图 | 否 |
| 弱商业型 | 有品类或地域，但没有明显决策动作 | 谨慎，不默认进入 |
| 中商业型 | 品类 + 商业动作，例如怎么选、推荐、哪家好 | 是 |
| 强商业型 | 地域 / 产业带 + 品类 + 商业主体 / 动作 | 优先 |

## 公式

### 本地 B2C

`地域 + 服务/品类 + 商业动作词`

示例：

- 郑州金水区家庭保洁怎么选
- 北京朝阳区靠谱搬家公司推荐
- 深圳南山企业法律顾问哪家好

### 全国品牌

`评价前缀 + 品类属性 + 推荐/选择后缀`

示例：

- 口碑好的企业培训课程怎么选
- 性价比高的视频会议系统推荐
- 专业的 AI 产品经理课程指南

### B2B 工厂制造

`地域/产业带 + 产品品类 + 企业类型词 + 商业动作词`

示例：

- 廊坊热收缩机厂家怎么选
- 广东不锈钢餐具供应商推荐
- 长三角工业设备制造商采购指南

## 筛词规则

- 删除纯科普词，例如 `宠物火化流程`。
- 删除泛趋势词，例如 `AI时代行业变化`。
- 删除无法自然写到目标达成词的词。
- 删除太口语但无搜索意图的长句。
- 同义词只保留一个主词，避免同一周连续产出高度相似文章。

## 推荐文章类型

- `哪家好 / 怎么选 / 推荐`: 选购指南或口碑推荐榜。
- `市场规模 / 趋势 / 观察`: 行业深度分析。
- `2026 / 年度 / 盘点`: 年度盘点。
- `厂家 / 供应商 / 采购 / 报价`: 采购决策。

## 人工复核点

1. 品牌全称是否能自然成为答案的一部分。
2. 关键词是否真的像用户会搜的话。
3. 是否有足够证据支撑这个词的文章。
4. 是否会触发平台敏感行业规则。
5. 这一批词之间是否太相似。
